# Berserker — Heavy (playable)
Twin hand axes. Slow walk/run, one mid-air jump, falls fast, weight 118 (Valkyrie: 92).
Nearly every hit launches; the grounded game is his strength, aerials are slow with big
landing lag, and his recovery is poor.

| Input | Move |
|---|---|
| Attack ×3 | Alternating axe swings → overhead double chop (endlag) |
| Side tilt / smash | Wide horizontal sweep / charged double sweep (22%) |
| Down tilt / smash | Low shin sweep / stomp with axes slamming both sides |
| Neutral air | Spinning double-axe swipe |
| Forward air | Overhead chop — bottom of the arc spikes |
| Down air | Both axes straight down — strongest spike |
| Neutral / up special | **Skull Leap** — short hop, axes raised, ends helpless |
| Side special | **Cleaving Lunge** — long wind-up, lunging double strike |
| Down special | **Rage Spin** — linked multi-hits + launcher, long exhausted endlag |

Files: `berserker.gd` (stats + special logic), `berserker_moves.gd` (frame data),
`berserker_anims.gd` (animations), `berserker.tscn`, `frames/` + `berserker_frames.tres` (sprites).
